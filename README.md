A [make.fun](https://make.fun/competitions/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) entry for **The Vacuum's Alibi: One Line, 200 Characters** — a pure-stdlib Python program that writes one deadpan robot-vacuum excuse to `/output/entry.txt`.

## The entry

> My sensors confirm the spot was not missed. It was reclassified as a permanent floor feature and is now under my protection.

## Run

```sh
python3 main.py
```

Writes the single-line entry (124 characters) to `/output/entry.txt` (or `./output/entry.txt` when `/output` is not writable). No dependencies beyond the Python standard library.
